Text styles

HTML (Hyper Text Markup Language) is the basic building block of the web.
It defines the meaning and structure of web content.Other technologies besides HTML are generally used to describe a web page's appearance presentation (CSS)or functionality behavior (JavaScript).

The HTML style attribute is used to add style to an element,such as color,font,size and more.


Bold-The "b" tagin HTML is used to specify thebold textwithout any extra importance.The text is within "b" tagdisplay in bold size.You can do that by using font-weight bold property in CSS.It is a container tag that contains an opening tag,content& enclosing tag


Italics-The"i" tagdefines a part of text in a alternate voice or mood.The content inside is typically displayed initalic.The "i" tagis often used indicate a technical term,a phrase from another language,a thought,a slip name,etc.


Underline-The "u" tagin HTML stands for underline.and it's used to underline the text enclosed within this "u" tag.This tag is generally used to underline misspelled words.This tag requires a starting tag as well as ending tag.
